## Daily Rules

Every day:

1. Review yesterday's mistakes for 10-20 minutes.
2. Learn the assigned topic from the listed docs.
3. Answer the daily question list without notes.
4. Drill 25-40 MCQs from the listed question bank.
5. Add all wrong or uncertain answers to `mistake-logs/mistake-log-san-phu-khoa.md`.

For each question, the learner should answer in this structure:

```text
Diagnosis / concept:
Key signs:
Needed tests:
Differential diagnosis:
First management principle:
One trap to avoid:
```
